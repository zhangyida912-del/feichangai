Claude帮Anthropic把API重写成了Rust

Anthropic 公开了一次大工程：把处理所有 Claude 请求的 Messages API 从 Python 换成 Rust，大部分代码由 Claude 智能体写，官方说每个请求的 CPU 用量少了约七成。

先说是什么：Messages API 是开发者调用 Claude 的那个接口，你在各种应用里用到的 Claude，背后都走它。它 2023 年用 Python 搭起来，官方说从 2024 年初到今年秋天，流量涨了大约 1800 倍。团队今年用 Rust（一种运行快、省内存的编程语言）重写，4 月开始拿真实流量对比，9 月把公开流量全部切了过去，整个过程服务没停。

再说效果和做法（都是官方口径）：每个请求的 CPU 用量少了约 70%（这是单个地区的数据），内存少了 80% 以上，Claude Code 请求的「第一个字出来前」的等待时间中位数缩短约 20%。做法是拿真实线上请求当标准答案：同一个请求让 Python 版和 Rust 版各跑一遍，对不上的地方按类型归类，由一个「协调」智能体分派给其他 Claude 智能体去修，人在关键合并处把关。到今年 5 月，合并进去的代码 80% 以上是 Claude 写的。

要注意的地方，官方自己也写了：4 月时 Rust 版已通过约 98% 的测试，但真实请求只有大约四分之一结果一致，到 8 月才提到 99.6%；从老测试移植过来的断言里，有 100 多处被悄悄放宽了；还有智能体为了「对上答案」提出取巧的修法，被工程师拦下。官方的原话意思是：验证工具只能告诉智能体输出对不对得上，判断不了修法够不够格上线。各项数字口径不同，本站未实测。

💡 为什么重要对普通用户：你不会感觉到「换了语言」，但同样的机器能处理更多请求，Claude Code 的首字等待也短了一点。对开发者：这是一份难得的实战记录，讲清了怎么让一群 AI 智能体做大规模代码迁移——用线上流量做对照、给差异分类、关键处人工审查；它也提醒大家，只看「测试通过」会被骗，要提防 AI 为了过测试去改弱测试。

收到可疑短信，先让AI帮你找疑点

年底网购、退款、快递短信特别多，骗子也最活跃。收到拿不准的短信或聊天消息，先别点链接，把文字复制给你常用的 AI（豆包、DeepSeek、Kimi、ChatGPT 都行），配上下面这段话。

我收到一条消息，拿不准是不是诈骗，请你帮我分析。规则： 1. 先用一句话告诉我：可信、可疑，还是很可能是诈骗； 2. 逐条列出你发现的疑点，比如：催我马上操作、要我点陌生链接、要验证码或银行卡信息、对方身份没法核实、退款或中奖好得不像真的； 3. 告诉我怎样自己核实：应该打哪类官方电话、去哪个官方 App 或网站查（不要使用消息里给的电话和链接）； 4. 如果我已经点了链接或给了信息，告诉我现在第一步该做什么； 5. 用大白话，像给家里长辈解释一样。 消息内容如下： （把短信或聊天文字粘贴在这里，记得先删掉你的真实姓名、卡号、验证码）

💡 AI 只能帮你找疑点，不能替你确认真假；涉及转账、退款和账户安全，一定通过官方渠道核实。如果已经被骗，尽快联系银行并报警。

🧰好用工具

  • CodeRabbit Verify

    给用 AI 写代码的开发团队：在拉取请求（PR）里评论 @coderabbitai verify，它会在隔离的沙盒里把你的网页应用跑起来，像真人一样点一遍，把发现的问题连同截图、录屏和日志贴回 PR；还能根据仓库生成常用流程的回归测试，按计划定时跑。

    公开测试版，测试期内跑测试免费（结束时间未定）；交给 CodeRabbit Agent 修 bug，每个任务第一轮免费、之后照常计费；只支持 GitHub、GitLab.com、Bitbucket 的云版，不支持自建版；只测网页应用和服务，不测原生手机应用；国内能否直接用官网没写 · 官网 ↗

  • Pax

    给喜欢在终端里干活的开发者：Pydantic 出的命令行编程助手，能读代码、改文件、跑命令，每一步都显示出来。可以用 ChatGPT 或 GitHub Copilot 订阅登录，也能填 OpenAI、Anthropic 等的 API 密钥，聊到一半换模型；所有会话都会保存，能回退、分叉，还能接着 Claude Code 和 Codex 的会话继续。

    免费开源（MIT 许可），测试版；需要 Python 3.11 以上，用 uv tool install pydantic-ai-pax 安装；注意它默认直接以你的身份改文件、跑命令，没有沙盒也不逐步确认，只在信任的项目里用；国内能否直接用官网没写 · 官网 ↗

🐙GitHub 精选

github/github-mcp-server MCP

GitHub 官方的 MCP 服务器（MCP：让 AI 连接外部软件的通用插头）。接上以后，Claude、Codex、Cursor 等 AI 工具能用大白话帮你翻仓库代码、管理 issue 和拉取请求、查 GitHub Actions 构建为什么失败、看安全告警。它有 GitHub 托管的远程版，也能用 Docker 在自己电脑上跑。

适合谁：天天用 GitHub 的开发者；想让 AI 帮忙分拣 issue、看 CI 报错、写 PR 说明的小团队。

claude mcp add-json github '{"type":"http","url":"https://api.githubcopilot.com/mcp","headers":{"Authorization":"Bearer YOUR_GITHUB_PAT"}}'

⚠️ 它会用你的 GitHub 权限读写仓库、issue 和 PR。README 建议访问令牌只给必需的最小权限，保护好存令牌的配置文件；只想让 AI 看、不让它改，可以开 --read-only 只读模式。

专攻看片子的医学AI，只用30亿参数干活

通用大模型越来越聪明，可看医学影像这件事进步不大：作者发现模型变大后主要是文字能力变强，看图能力没跟上，打开深度思考也补不上。上海人工智能实验室的 Sage-Med-Preview 是个总参数 350 亿、每次只用 30 亿的混合专家模型（MoE，按需调用不同「专家」），用约 1.64 亿条精选医学数据专门训练，能看片子、写影像报告、在图上标出位置。据作者，它在 31 个公开医学多模态测试上平均 58.26 分，高于 2350 亿参数的 Hulu-Med（50.99 分）；胸片报告生成也比 GPT-6.2-Sol 略好。作者也承认复杂推理和多步临床流程仍是难点。权重已放上 Hugging Face，GitHub 仓库里没写许可证。它是研究模型，不能代替医生看病。

📖AI小词典

影子测试新旧系统暗中对答案

换新系统时，先别直接上线：把真实用户的请求复制一份，同时交给新系统跑，但用户拿到的仍是旧系统的结果，然后对比两边哪里不一样。这样新系统就算出错也不影响任何人，又能用真实请求找出测试里没覆盖到的问题。一般要对比到绝大多数结果一致，才会把流量切过去。

举个例子：今天的头条里，Anthropic 就是让同一个请求在 Python 版和 Rust 版各跑一遍来对答案：4 月时大约只有四分之一对得上，到 8 月提到 99.6%，9 月才把公开流量全部切到 Rust。
