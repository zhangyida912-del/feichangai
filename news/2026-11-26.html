Claude做的小工具，能装成电脑应用了

让 Claude 做的小网页工具（Artifacts），现在点一下就能装到 Mac 或 Windows 电脑上，有自己的图标和窗口，像普通软件一样打开。

先说谁能用：官方说所有套餐都能用，现在是测试版，在 Claude 的 Mac 和 Windows 桌面应用里逐步推送。用法很简单：打开一个 Artifact，在「分享」菜单里点「Install as app」。不用打包签名，也不用 API 密钥，直接用你的 Claude 账号登录。Team 版默认打开；企业版要等管理员打开；符合 HIPAA（美国医疗隐私法规）要求的组织和混合部署暂时用不了。

再说能干什么：装好的应用可以调用 Claude 和你接好的连接器，能弹通知、在菜单栏或系统托盘里放个图标；你改了原来的 Artifact，应用会自动更新。权限分三档：默认只能做浏览器里能做的事；第二档能置顶窗口、用全局快捷键、发通知；最高一档是「完全访问电脑」，可以运行程序、读写和删除文件，不用每次问你。

要注意：它得联网、登录 Claude 才能打开，不是离线的独立软件；应用里调用 Claude 也算你套餐的用量。每次应用更新（包括你自己改），都要重新给权限；但应用里从别的网站加载的内容，变了不会再问你。Anthropic 不会事先审查这些应用，「完全访问」只能给你自己做的、或同公司同事做的应用。Claude 文档、幻灯片、表格类的 Artifact 不能装。

💡 为什么重要对普通用户：以前「让 AI 帮我做个小工具」，做完只能在聊天窗口里用；现在能把记账表、倒计时、练习小测这类东西放到桌面上天天用，门槛又低了一截。但给「完全访问电脑」权限前要想清楚，别人分享来的应用尤其要小心。对开发者：做个内部小工具不用再搭框架、打包、签名，团队内部分享很方便；企业要提前想好管理员怎么配权限。

年底了，让AI陪你复盘这一年

离 2026 年结束只剩一个多月。把下面这段复制给你常用的 AI（豆包、DeepSeek、Kimi、ChatGPT 都行），它会一个一个问你问题，最后帮你整理成一页年终小结。

请你当我的年终复盘教练，帮我回顾这一年。规则： 1. 每次只问我一个问题，等我回答后再问下一个，一共不超过 8 个问题； 2. 问题要覆盖：工作或学习、身体和作息、家人朋友、钱怎么花的、学会的新东西、最遗憾的一件事； 3. 我回答得太笼统时，追问一个具体例子； 4. 问完后，帮我整理成一页小结：今年做得好的 3 件事、想改进的 3 件事、明年第一季度能马上开始的 3 个小行动（要具体到每周做什么）； 5. 语气像朋友聊天，不要说教。 准备好了就问第一个问题。

💡 不用把身份证号、银行卡、病历这类隐私写进去；聊到钱和身体时，AI 的建议只能参考，真要做决定还是问专业人士。

🐙GitHub 精选

anthropics/skills Skill

Anthropic 官方的技能（Skill）合集。Skill 就是给 AI 的一份操作说明书，装上以后它能用固定方法完成某类任务。这里有十几个现成的：做 Word、PDF、PPT 和表格，前端页面设计，自动测试网页，帮你搭 MCP 服务器，还有一个专门教你写自己的 Skill 的「skill-creator」。

适合谁：用 Claude Code 写代码、做文档的开发者；想学怎么写 Skill 的人，可以直接拿来当模板。Claude 网页版的付费用户已经内置了这些示例技能，不用另装。

/plugin marketplace add anthropics/skills /plugin install document-skills@anthropic-agent-skills
📄 多数为 Apache 2.0 开源，以各技能文件夹里的说明为准🕒 最近更新 2026-11-16👤 Anthropic 官方

AI操作电脑时，别让它看「过期」的屏幕

让 AI 替你点鼠标、操作电脑（电脑操作智能体）有个毛病：它截图、思考要花好几秒，等它动手时，屏幕可能早就变了，结果点错地方。这篇论文给它配了个只有 8 亿参数的小「哨兵」NightWatch，一直盯着屏幕：发现画面变了就打断 AI 的思考、作废已经过时的操作，等页面加载完再叫醒它。原来的 AI 模型和提示词都不用改。据作者介绍，在 OSWorld 测试里，非推理部分的耗时少了 33%、白白浪费的时间少了 53%，成功率基本不变；在一个专测动态界面的测试里，成功率从 39.5% 提到 44.2%。代码和模型已开源（Apache 2.0）。

📖AI小词典

开放权重模型「成品」可以下载

AI 模型学到的本事，都存在一大堆数字里，这些数字叫「权重」。开放权重就是把这些数字公开让人下载，你可以在自己的电脑或服务器上跑，甚至接着训练。但它不等于「开源」：训练用的数据和代码往往不公开，许可证也可能限制商用，要看清楚是哪种许可。

举个例子：今天快讯里的百度 ERNIE 5.5 Flash 预览版和 Bonsai 2.5 27B 都用 Apache 2.0 许可开放了权重，比较宽松，商用也可以；而 Cognition 的 SWE-2.1 没说开放权重，只能在它自家产品里用。
