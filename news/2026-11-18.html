Gemini 4 Hydrogen向所有人开放：日常任务的主力模型，API每百万token 1.5／7.5美元

Google于11月12日推出Gemini 4 Hydrogen，定位是“智能体工作流的日常主力”：Carbon和Argon负责深度、长时间的推理，Hydrogen负责快速执行，也是从Gemini 3.8 Flash迁移的升级选项。思考强度分low、medium、high（默认）和新增的xhigh。

开放范围比Carbon宽得多：Gemini应用面向所有人开放（官方脚注说明，免费用户是在系统自动选模型时按需用到）；Google搜索面向全球用户；开发者可在Google AI Studio、Android Studio通过Gemini API调用；企业经Gemini for business使用；Antigravity限Google AI Pro和Ultra付费订阅者，Google表格里的Gemini也先从这两档开始。API价格为每百万输入token 1.5美元、输出7.5美元，官方说明在100万token上下文内统一定价，不分长短档；缓存价公告没有写。

Google称它在Artificial Analysis智能指数上得51分（xhigh档54分），略高于Argon的50分，Terminal-Bench 4.1为57%，完成任务比3.8 Flash快2.5倍，捏造内容减少5倍以上，均为Google口径。对普通用户来说，它多半就是Gemini里默认会碰到的那个新模型；对开发者来说，价格低于Neon和Carbon，适合量大的日常调用。本站未调用模型。

腾讯开放Hy4 flash权重：220B总参数、12B激活，可以自己部署

据媒体报道，腾讯于11月16日发布Hy4 flash，并在Hugging Face放出Hy4 flash、FP8版和预训练基座Hy4 flash-base三份权重。模型卡显示：总参数2200亿（含640亿Engram参数），每个token只激活约120亿；上下文100万token；原生支持文本和图像输入，输出文本。可用vLLM、SGLang、Transformers部署，也有GGUF版本。

许可是“Tencent Hy License 1.0”，由Apache 2.0改写而来，主要多了针对“模型即服务”（MaaS）的商业条款：对外提供API推理或微调服务的企业，如果全球年营收超过5000万美元，或产品月活超过1亿，需要先拿到腾讯书面授权；只在内部使用、不把模型和输出提供给第三方的不受这条限制。许可里没有地区限制。因为有附加条款，本站称它“开放权重”。

腾讯给它的定位是日常办公任务，长时间软件工程仍推荐Hy4。官方称在自建的WorkIndex上得42.1分（Hy4 preview为39.7），单任务成本约为Hy4的1/20；85名内部用户的盲测满意度为2.79/4。这些都是腾讯内部评测，本站未下载或部署。腾讯官网新闻稿读取失败，云API价格未能核对，本文不写。

微软发布MAI Code 2：先进GitHub Copilot，官方承认还不擅长长任务

微软11月17日在Ignite大会发布两款自研编程模型。MAI Code 2面向把代码推到生产、深度调试、多文件实现、全仓库推理和界面开发；MAI Code 2 Flash面向量大的轻活，比如解释代码、定点修改、常规修复。两款都已在GitHub Copilot中可用；Flash另在Microsoft Foundry开放有限访问预览。OpenRouter、Vercel、OpenCode、Kilo等渠道标为“即将”。

微软称，在DeepSWE、Terminal Bench、SWE-Atlas、FrontierCode四项平均下，MAI Code 2达到GPT-6.1 Sol 98%的水平、成本为其40%；达到Claude Opus 5.5 96%的水平、成本为其5%；Flash与GPT-6 Luna、Claude Haiku 5.5相当。需要注意，页面上的成本按“50%促销价”计算，公告没有给出原价、API价格、Copilot里的消耗倍率和上下文长度。

微软在公告中直接写明，这两款模型“还没有为更难的问题调优”，包括基础科研和很长的智能体任务。所以更适合日常业务代码，而不是替代长时间自主编程。跑分为微软口径，本站未在Copilot中实测。

商汤开源SenseNova-Loop-9B：中间层跑两遍，Apache 2.0许可

商汤11月17日发布SenseNova-Loop-9B正式版（10月31日先出过预览版）。它约90亿参数，32层解码器中第4到27层共享权重、循环执行两遍，相当于约146亿参数的推理计算量；支持文本和图像输入、输出文本，上下文最长51.2万token。权重在Hugging Face，许可为Apache 2.0，属于真正的开源；4bit量化版约4.9GB。

商汤自己写明，编程和通用智能体任务的稳定性“仍有待提升”，复杂指令遵循也是短板；官方对比中，NL2Repo得分41.36，低于Qwen3.8-27B的44.60。适合想在本地试循环架构的开发者，本站未下载测试。
