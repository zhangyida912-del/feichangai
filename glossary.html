📖 AI 小词典

新闻里看不懂的 AI 词，这里用大白话讲清楚。每天新增一个。

已收录 29 个词 · 每天更新

投机解码 小模型打草稿，大模型改卷

大模型生成文字是一个字一个字往外蹦，每蹦一个都要把整个大模型算一遍，很慢。投机解码的办法是：让一个小得多的「草稿模型」先快速猜出后面几个字，再让大模型一次性检查——猜对的直接收下，猜错的从错的地方重来。因为最后都由大模型把关，结果和原来一样，只是更快；猜得越准，提速越多，常见能快大约 2～4 倍。

举个例子：今天快讯里腾讯开源的 DFly2 就是这样的草稿模型：它借用大模型自己的缓存来打草稿，官方说在 Hy4 flash 的智能体任务上解码最高快约 4.5 倍。

影子测试 新旧系统暗中对答案

换新系统时，先别直接上线：把真实用户的请求复制一份，同时交给新系统跑，但用户拿到的仍是旧系统的结果，然后对比两边哪里不一样。这样新系统就算出错也不影响任何人，又能用真实请求找出测试里没覆盖到的问题。一般要对比到绝大多数结果一致，才会把流量切过去。

举个例子：今天的头条里，Anthropic 就是让同一个请求在 Python 版和 Rust 版各跑一遍来对答案：4 月时大约只有四分之一对得上，到 8 月提到 99.6%，9 月才把公开流量全部切到 Rust。

第11期 · 原文

开放权重 模型「成品」可以下载

AI 模型学到的本事，都存在一大堆数字里，这些数字叫「权重」。开放权重就是把这些数字公开让人下载，你可以在自己的电脑或服务器上跑，甚至接着训练。但它不等于「开源」：训练用的数据和代码往往不公开，许可证也可能限制商用，要看清楚是哪种许可。

举个例子：今天快讯里的百度 ERNIE 5.5 Flash 预览版和 Bonsai 2.5 27B 都用 Apache 2.0 许可开放了权重，比较宽松，商用也可以；而 Cognition 的 SWE-2.1 没说开放权重，只能在它自家产品里用。

第10期 · 原文

智能体 会自己动手干活的 AI

普通聊天 AI 是你问一句、它答一句；智能体（Agent）则是你给它一个目标，它自己拆步骤、调用工具（搜网页、读文件、写代码、点按钮），做完一步看看结果再决定下一步，直到把事办完。它能干的事更多，但出错时也更难察觉，所以重要操作最好让人把关。

举个例子：今天的趣闻里，DeepMind 让几组 Gemini 智能体各自琢磨量子算法、定时开会交流，每个点子还要先通过证明检查——这就是让智能体干活、再给它加上「把关」的典型做法。

token AI 读写文字的「字块」

AI 不是一个字一个字地读，而是把文字切成一小块一小块，每一块叫一个 token。中文大约一个汉字算 1 到 2 个 token，英文大约 4 个字母算 1 个。AI 的价格、能记住多长的内容（上下文），都是按 token 算的。

举个例子：今天头条说 Astra「每百万 token 输入 8 美元」，大致就是喂给它五十万到一百万个汉字收 8 美元；它写出来的部分（输出）更贵，每百万 token 40 美元。

第8期 · 原文

大模型 读过海量文字的 AI

大模型就是用海量文字（有的还加上图片、声音）训练出来的 AI 程序，学会了文字之间的规律，所以能聊天、写作、翻译、写代码。ChatGPT、豆包、DeepSeek、Claude 背后都是大模型。「大」主要指参数多、训练数据多。

举个例子：你在聊天软件里问问题，真正在背后回答的就是一个大模型。

基础词条

提示词 你对 AI 说的话

提示词（Prompt）就是你输入给 AI 的那段话。说得越清楚——你是谁、要做什么、要什么格式、有什么限制——AI 的回答通常越好。专门研究怎么写提示词，叫「提示词工程」。

举个例子：「帮我写个请假条」和「我明天要带孩子看病，帮我给领导写一段两三句话的请假消息，语气客气」，后者就是更好的提示词。

基础词条

上下文 AI 一次能记住的内容

上下文（Context）指 AI 在一次对话里能同时「看到」的全部内容，包括你之前说的话、它的回答和你上传的文件。上下文长度按 token 算，超过上限，最早的内容就会被忘掉或截掉。

举个例子：说某个模型有「100 万 token 上下文」，大致意思是它一次能读进几十万到上百万个汉字的内容。

基础词条

幻觉 AI 一本正经地说错

幻觉是指 AI 编出听起来很像真的、但其实是错的内容，比如不存在的书名、错误的数字、假的法律条文。原因是大模型本质上在「猜下一个词」，不是在查资料库。所以重要的信息一定要自己核对。

举个例子：让 AI 推荐几篇论文，它可能编出作者和标题都很像样、但根本不存在的论文。

基础词条

多模态 能看图、听声音的 AI

多模态是指 AI 不只能处理文字，还能理解或生成图片、声音、视频等多种形式的内容。比如拍一张照片问它这是什么花，或者让它根据一段话画一张图。

举个例子：新闻里说某模型「能看图看视频」，就是说它是多模态模型。

基础词条

推理模型 先想一想再回答的 AI

推理模型在回答之前，会先在内部一步步思考、检查，再给出答案。它做数学题、写代码、分析复杂问题更准，但通常回答更慢、也更贵。很多产品让你选「快速」还是「深度思考」，就是在选要不要多推理。

举个例子：日报里说某模型有「思考强度 Low 到 Extra High 四档」，档位越高，它想得越久、越仔细。

基础词条

参数 模型的「脑细胞」数量

参数是模型内部用来存储学到的规律的数字，数量常用「B」（十亿）表示。参数多通常意味着能力更强，但也需要更多算力来运行。不过参数不是唯一标准，训练数据和方法同样重要。

举个例子：「27B 模型」就是大约有 270 亿个参数的模型。

基础词条

MoE 按需叫专家来干活

MoE（混合专家）是一种模型结构：模型里有很多个「专家」小网络，每次处理问题时只调用其中一部分。这样总参数可以很大，但每次实际用到的不多，速度更快、成本更低。

举个例子：日报里写「220B 总参数、12B 激活」，就是总共 2200 亿参数，每次只用其中约 120 亿。

基础词条

微调 给模型补一门专业课

微调是在一个已经训练好的通用模型基础上，再用某一类专门的数据继续训练，让它更擅长某个领域或某种风格，比如客服、法律、医疗问答。成本比从头训练低很多。

举个例子：一家公司拿自己的客服记录去微调一个开源模型，让它回答问题更像自家客服。

基础词条

RAG 先查资料再回答

RAG（检索增强生成）是让 AI 回答前，先从指定的资料库（比如公司文档、知识库）里查出相关内容，再根据查到的内容来回答。这样回答更有依据，也能用上模型训练时没见过的新资料，还能减少幻觉。

举个例子：很多「上传文档后问答」的功能，背后用的就是 RAG。

基础词条

蒸馏 大模型教小模型

蒸馏是用一个强大但昂贵的大模型的回答，去训练一个更小、更便宜的模型，让小模型学到大模型的大部分本事。这样小模型可以在手机、普通电脑上跑，成本也更低。

举个例子：很多「轻量版」「Flash 版」模型，就用到了蒸馏的方法。

基础词条

量化 给模型「压缩瘦身」

量化是把模型里的参数用更少的位数来存（比如从 16 位压到 4 位甚至更少），让模型文件变小、跑得更快、占用内存更少，代价是效果会略有下降。想在自己电脑上跑大模型，通常要用量化版。

举个例子：日报里那个「5.9GB 的 27B 模型」，就是把参数压到了只有 -1、0、1 三种值，才变得这么小。

基础词条

API 程序之间对话的接口

API 是让一个程序调用另一个程序功能的接口。开发者通过 API 把大模型接进自己的应用里，按用了多少 token 付费。普通用户用聊天软件不需要 API；做开发、做产品才会用到。

举个例子：价格表里「每百万 token 输入 8 美元」，说的就是通过 API 调用模型的价格。

基础词条

MCP AI 连接软件的通用插头

MCP（模型上下文协议）是一套让 AI 连接外部软件和数据的通用标准，就像 USB 接口。软件只要做一个 MCP 服务器，各家支持 MCP 的 AI 就都能连上它，读数据、帮你操作。

举个例子：日报里说 Google Workspace 的 MCP 服务器正式可用，意思是 AI 能用这套标准接口读你的 Gmail、文档等（需要你授权）。

基础词条

Skill（技能） 给 AI 的一份操作说明书

Skill 是一个打包好的文件夹，里面有说明文档、模板，有时还有脚本，教 AI 用固定的方法完成某类任务，比如按公司格式做报告、处理表格。AI 遇到相关任务时会自动读取并照着做，不用你每次重新解释。

举个例子：日报里说 MCP 服务器能「附带技能」，就是连上一个软件时，顺便带上一份怎么用好它的说明书。

基础词条

Token 价格 AI 按「字块」收费

大模型 API 按 token 数量收费，一般分「输入」（你发给它的内容）和「输出」（它写出来的内容），输出通常更贵。有的还有更便宜的「缓存输入」，就是重复出现的内容不用按原价算。

举个例子：看价格表时，同一个模型「输入 $2、输出 $10」，说明它写出来的内容单价是读进去的 5 倍。

基础词条

开源 代码公开，大家能用能改

开源软件把源代码公开，按开源许可证（如 MIT、Apache 2.0）允许别人免费使用、修改、分发。AI 领域常说的「开源模型」，严格来说多数只是开放了权重，训练数据和代码不一定公开，许可也可能有限制。

举个例子：日报里会区分「开源」和「开放权重」：许可有限制的，只写开放权重。

基础词条

跑分 AI 的考试成绩

跑分是用一套标准测试题（基准测试）给模型打分，方便比较不同模型的能力，比如数学、编程、看图。但厂商自己公布的跑分可能挑了对自己有利的测试，所以日报会标「官方口径」，没实测过的标「未实测」。

举个例子：「在 Terminal-Bench 上从 24.2 分涨到 50.0 分」，就是一项编程能力测试的跑分。

基础词条

思维链 AI 的草稿纸

思维链是让 AI 把解题过程一步步写出来，而不是直接给答案。一步步想能明显提高复杂问题的准确率。推理模型就是把这种「先打草稿」的能力练得更强。

举个例子：你在提示词里加一句「请一步步分析」，就是在引导它用思维链。

基础词条

端侧模型 装在你手机电脑里的 AI

端侧模型是直接在手机、电脑等设备上运行的小模型，不用联网把数据传到服务器。好处是更快、更省钱、隐私更好；缺点是能力一般比云端的大模型弱。

举个例子：一些手机自带的 AI 修图、离线翻译，用的就是端侧模型。

基础词条

系统提示词 AI 的「岗位说明」

系统提示词是在对话开始前，开发者或你自己预先给 AI 设定的规则，比如「你是一名英语老师，只用简单词汇」。它会影响整个对话里 AI 的语气和行为。很多 AI 应用的「自定义指令」就是在设系统提示词。

举个例子：在 AI 设置里写上「回答尽量简短，用中文」，之后每次对话它都会照做。

基础词条

AGI 什么都能干的通用 AI

AGI（通用人工智能）指在大多数领域都能达到或超过人类水平的 AI，而不只是擅长某几件事。它现在还没有公认的定义和标准，各家公司说「接近 AGI」时，标准往往不一样，听的时候要打个问号。

举个例子：看到「某某模型离 AGI 只差一步」这类说法，多半是观点而不是事实，日报会标成「观点」。

基础词条

算力 AI 的「发动机马力」

算力指计算机做计算的能力，训练和运行大模型都需要大量算力，主要靠 GPU（显卡芯片）等专用芯片。算力贵且紧缺，所以模型越大、用的人越多，成本就越高，这也是 API 要收费的原因之一。

举个例子：新闻里各家公司抢购英伟达芯片、建数据中心，都是在抢算力。

基础词条

对齐 让 AI 守规矩、讲道理

对齐是让 AI 的行为符合人类的意图和价值观：该帮忙时认真帮忙，不该做的事（比如教人做坏事）拒绝。各家公司都有专门的团队做对齐和安全测试。

举个例子：日报里提到模型对高风险网络安全请求「管得更严」，就是对齐和安全策略的一部分。
