## 01 Anthropic Messages API 迁移到 Rust（头条）
出处：https://www.anthropic.com/research/migrating-api-to-rust ，公告日期 2026-11-25（页面标注发布与修改均为11-25）。
线索来源：The Neuron 当周新闻汇总、Techmeme。
状态「已上线」依据：原文写明公开流量已于2026年9月全部切到 Rust 版，现已在线服务。
原文核对要点：API 2023年用 Python 搭建；2024年初至2026年秋流量增长约1800倍；2026年3月曾做局部 Rust 改写，只省8–10% CPU，被判定不值得，随后整体重写（正文不写具体开工月份）；4月起做影子对比；9月切换公开流量。每请求 CPU 约降70%（单一地区数据）、每请求内存降80%以上（全生产环境）、首 token 延迟中位数降约20%（仅 Claude Code 客户请求、观察期较短）。截至2026年5月，合并代码80%以上由 Claude 编写。4月 Rust 版通过约98%测试，但生产输入仅约24%一致；8月一致率99.6%。移植测试中发现100多处被放宽的断言；有智能体提出为通过验证而取巧的修法，被工程师否决。协调智能体按差异类型分派工作智能体；人工在循环交界处审查 PR。
边界：所有数字为官方口径，本站未实测；未写「会因此降价或放宽限额」，原文没有这样说。未逐字引用原文。

## 02 inclusionAI Ling-3.2-air（快讯）
出处：https://huggingface.co/inclusionAI/Ling-3.2-air （模型卡）。页面无明确发布日期，合集显示约3天前更新；媒体（TechNode）11-25 报道，正文日期写「媒体报道日期」。
线索来源：The Neuron 新闻汇总。
状态「可下载」依据：Hugging Face 提供 BF16 与 FP8 权重，许可标签 MIT。
原文核对要点：模型概览表写总参数124B、激活5.5B；页面标题与 Safetensors 组件写128B，正文注明口径不一。支持图片、视频输入；推荐上下文 262144（约25.6万 token）；推荐 4 张 141GB 级显卡（H20-3e／H200）或 4 卡 Blackwell 节点，80GB 卡需 8 卡并行；SGLang（推荐）或定制 vLLM 分支。AutomationBench-AA 由 Ling-3.0-flash-VL 的15.7%升至61%（官方口径）；模型卡写明暂无托管推理服务。
边界：Terminal-Bench、法律测试幻觉检查后通过率很低（0.8%）等数字未写入正文，以免篇幅过长；未实测。
