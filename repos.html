MCP

github/github-mcp-server

GitHub 官方的 MCP 服务器（MCP：让 AI 连接外部软件的通用插头）。接上以后，Claude、Codex、Cursor 等 AI 工具能用大白话帮你翻仓库代码、管理 issue 和拉取请求、查 GitHub Actions 构建为什么失败、看安全告警。它有 GitHub 托管的远程版，也能用 Docker 在自己电脑上跑。

适合谁：天天用 GitHub 的开发者；想让 AI 帮忙分拣 issue、看 CI 报错、写 PR 说明的小团队。

claude mcp add-json github '{"type":"http","url":"https://api.githubcopilot.com/mcp","headers":{"Authorization":"Bearer YOUR_GITHUB_PAT"}}'

📄 MIT · 🕒 2026-11-25 · 👤 GitHub 官方
⚠️ 它会用你的 GitHub 权限读写仓库、issue 和 PR。README 建议访问令牌只给必需的最小权限，保护好存令牌的配置文件；只想让 AI 看、不让它改，可以开 --read-only 只读模式。

Skill

anthropics/skills

Anthropic 官方的技能（Skill）合集。Skill 就是给 AI 的一份操作说明书，装上以后它能用固定方法完成某类任务。这里有十几个现成的：做 Word、PDF、PPT 和表格，前端页面设计，自动测试网页，帮你搭 MCP 服务器，还有一个专门教你写自己的 Skill 的「skill-creator」。

适合谁：用 Claude Code 写代码、做文档的开发者；想学怎么写 Skill 的人，可以直接拿来当模板。Claude 网页版的付费用户已经内置了这些示例技能，不用另装。

/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills

📄 多数为 Apache 2.0 开源，以各技能文件夹里的说明为准 · 🕒 2026-11-16 · 👤 Anthropic 官方
⚠️ 官方说明这些技能主要用于演示和学习，用在重要工作前要自己先测试。Skill 里可能带脚本，会在你电脑上运行。

MCP

modelcontextprotocol/servers

MCP（让 AI 连上各种软件的通用接口）官方的参考服务器合集：读写本地文件、抓取网页内容、操作 Git 仓库、给 AI 加「记忆」、时间换算等。每个都是一个小例子，教你一个 MCP 服务器怎么写。

适合谁：想给 AI 接上自己的文件和工具，或者想自己写 MCP 服务器的开发者。

📄 正在从 MIT 迁移到 Apache 2.0，新代码为 Apache 2.0 · 🕒 2026-11-18 · 👤 MCP 官方项目
⚠️ 官方说明这些是演示用的参考实现，不是正式产品。文件系统这类服务器能读写你的文件，一定要限定它能访问的文件夹。
