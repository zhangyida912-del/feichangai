编程

Fleetify

给同时开好几个写代码 AI 的开发者用：在一个桌面应用里并排跑 Claude Code、Codex、OpenCode 等，每个任务自动分到单独的 git 工作区，还能看每个会话花了多少 token 和钱、统一审批工具调用。

免费开源（GitHub 标 MIT 许可），需注册免费账号、自带 API 密钥；支持 macOS、Windows、Linux，安装包暂未签名，首次打开会有系统警告；国内能否使用官网没写

隐私安全

Almma's PII Guard

怕在 Claude 里不小心贴出个人信息的人用：一个 Chrome 扩展，发送前标出输入框里的姓名、邮箱、电话、证件号、地址等，也能自己加要拦的名字和格式。商店页说完全在本机运行，不联网、不需要账号。

Chrome 扩展，价格商店页没写；只检查 claude.ai 等指定网站的输入框，不查附件和图片；目前用户很少；国内能否使用官网没写

视频

tday.com

给要做产品演示视频的开发者和团队用：让 Claude Code、Cursor、Codex 等写代码 AI 在你自己电脑上操作正在运行的应用，自动录一段带配音、鼠标轨迹、放大镜头和字幕的演示，录完还能改。官网说源代码不会离开你的电脑。

免费版可存 5 个演示，Pro 每月 39 美元；有 Mac 下载，官网没提 Windows；国内能否使用官网没写

智能体

Granular.Build

不会写代码的创业者、设计师、产品经理也能用的桌面 AI 工作台：一个「总管」智能体把活分给多个干活的智能体，每个在自己的终端和项目副本里做事，带实时预览。用你自己已有的 Claude、Codex、Gemini 等订阅。

免费下载，免费版限 2 个项目；Pro 每月 12.99 美元；支持 Mac，Windows 版还在测试；国内能否使用官网没写

图片

Gemini 图片工具

在 Gemini 里用一句话生成图片；上传照片，让它照你说的改；还能把几张图合成一张新图，或者做一段 3 秒左右的循环 GIF。

部分模型要 Google AI 付费计划；GIF 只在美、日、韩、英等 8 个国家逐步开放，还要付费计划；修图需年满 18 岁；国内无法直接使用

编程

Trix

给同时开好几个写代码 AI 助手的人用：Claude Code、Codex、Gemini CLI 等在一个终端里并排跑，哪个在干活、哪个在等你回复、哪个做完了，一眼就能看到；按一个快捷键直接跳到等你最久的那个。

开源（MIT 许可）；支持 Linux 和 macOS，官网没提 Windows
